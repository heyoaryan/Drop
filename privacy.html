Core Security Architecture

Ephemeral 4-Digit Sessions

Every session lives in its own isolated numeric namespace (e.g. 4821). The code is known only to the devices you invite — nothing persists after you close the tab.

True Hard Delete

One click permanently removes both the PostgreSQL database row and the binary file from Supabase Storage simultaneously — no soft-delete, no recovery.

On-Device EXIF Stripping

Photos are re-encoded through the browser Canvas API before upload. This automatically strips EXIF metadata — device IDs, GPS coordinates, timestamps — as a privacy side-effect.

Zero Ad Trackers

Drop ships no Google Analytics, Meta Pixels, or third-party scripts of any kind. We never fingerprint your browser, hardware, or network. What you share stays between you.

Frequently Asked Questions

Can someone guess my 4-digit session code?
Sessions are short-lived and randomly generated from 10,000 combinations. Because they're ephemeral and you can hard-delete everything in one click, even a correct guess gives no lasting access.
Is there any virus / malware risk when downloading files?
Files are transferred exclusively between devices sharing the same session code. Supabase Storage treats files as raw binary blobs and does not execute them server-side.
Does my data remain on any server after deletion?
No. Deleting an item triggers a hard purge: the PostgreSQL row is deleted and the file object is removed from Supabase Storage in the same operation — instantly and permanently.
Does Drop access my camera or microphone?
Never. Drop only requests access to files you explicitly select or drag in. No camera, microphone, location, or contact permissions are ever requested.
