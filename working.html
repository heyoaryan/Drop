Why This Architecture

Most file sharing tools require installing an app, creating an account, or sharing a phone number. Drop eliminates all of that by running entirely in the browser, talking directly to Supabase — no intermediate server, no backend code to maintain.

The entire app is a single HTML file. Supabase handles the database, real-time WebSocket push, and file storage bucket — everything else runs on your device.

The 5-Step Sync Pipeline

STEP 01

Session Pairing

A random 4-digit code is generated and embedded in the URL hash. The second device opens the link or types the code — instantly in the same room, no account needed.

supabase.channel('session-4829')
STEP 02

Client-Side Compression

Photos are re-encoded in-browser via the Canvas API — capped at 1400px, 75% JPEG quality. Cuts payload by ~80% and strips EXIF (GPS, device ID) as a privacy side-effect.

canvas.toBlob(b => upload(b), 'image/jpeg', 0.75)
STEP 03

Storage Upload

Files stream directly to the Supabase drop_files bucket under a session-scoped path. A public CDN URL is returned immediately and written to the database.

storage.from('drop_files').upload(path, file)
STEP 04

Realtime Broadcast

Supabase Realtime monitors the PostgreSQL Write-Ahead Log and pushes the INSERT event over an open WebSocket to every device in the session — no polling, sub-second delivery.

.on('postgres_changes', { event: 'INSERT', ... })
STEP 05

One-Click Receiving

Items appear instantly on the receiver's screen. Single tap to download, copy to clipboard, open in new tab, or trigger the native Web Share sheet on mobile.

Frequently Asked Questions

How fast is the transfer?
On a normal Wi-Fi or mobile connection, items appear on the receiving device in under a second. The Supabase Realtime WebSocket push averages ~38ms. Upload speed depends on file size and your connection.
Does Drop work without an internet connection?
No. Drop relies on Supabase's cloud infrastructure for storage and real-time delivery. Both devices need an active internet connection — though they don't need to be on the same network.
Is there a file size limit?
The Supabase storage bucket is configured with a 50 MB per-file limit. Images are compressed client-side first, so a 15 MB photo typically becomes 2–3 MB before upload.
Can I use Drop between different networks?
Yes — that's the point. Your phone on mobile data and your laptop on office Wi-Fi work perfectly. All traffic routes through Supabase, so there are no local network or Bluetooth range restrictions.
